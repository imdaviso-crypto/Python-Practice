# Project 002 – Greeting Program

## Objective

Create a Python program that accepts user input and displays a personalized greeting.

---

## Project Description

This project builds upon Project 001 by introducing user interaction. Rather than displaying a fixed message, the program asks the user for their name and generates a personalized greeting.

This project marks the beginning of creating dynamic programs that respond to user input.

---

- Basic program flow

## Reflection

This project introduced one of the most important concepts in programming: user interaction.

Instead of producing the same output every time, the program now changes based on the information provided by the user. This demonstrated how variables can store data and how programs can respond dynamically to different inputs.
