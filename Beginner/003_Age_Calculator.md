# Project 003 – Age Calculator

## Objective

Create a Python program that accepts the user's age, performs a mathematical calculation, and displays how old they will be next year.

---

## Project Description

This project builds upon Project 002 by introducing numerical input and basic arithmetic. Rather than simply displaying information, the program now performs a calculation using data provided by the user.

This project represents my first experience using Python to manipulate numerical data instead of only displaying text.

---

## Skills Learned

- `input()`
- `int()`
- Variables
- Basic arithmetic
- `print()`
- Reading Python error messages
- Debugging syntax errors

---

## Challenge

During development, the program would not execute because I accidentally omitted the closing quotation mark after `("How old are you?")` on the first line. Although the mistake was small, it prevented Python from interpreting the program correctly and resulted in a syntax error.

---

## Solution

I carefully reviewed Python's error message and accepted the suggested correction. After locating the missing quotation mark and updating the code, the program executed as intended. This reinforced the importance of slowing down and carefully checking syntax before assuming a larger problem existed.

## Reflection

This project was my first experience performing calculations using user input. While the programming concepts were straightforward, a single missing quotation mark prevented the program from running entirely. It was a reminder that attention to detail is just as important as understanding the underlying concepts.

I also began to appreciate the value of Python's error messages. Rather than viewing them as obstacles, I found they pointed directly toward the issue and made troubleshooting much more efficient.
